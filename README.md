# sukima-support

The public support site for Sukima, an unofficial companion for Anki on Apple Watch, made by Bibu Workshop.

Static HTML for GitHub Pages: no build step, no scripts, no analytics, no fonts or files from other servers.

| Page | File | Public address |
|---|---|---|
| Home | `index.html` | bibuworkshop.com/sukima |
| Support | `support/index.html` | bibuworkshop.com/sukima/support |
| Privacy policy | `privacy/index.html` | bibuworkshop.com/sukima/privacy |
| Setup guide | `help/index.html` | bibuworkshop.com/sukima/help |

The words come from the product documents (`docs/release/privacy-policy.md`, approved as DEC-124, and `docs/release/support-site.md`). Change them there first, then here.
